Build from source

git clone https://github.com/deraldg/x64base
cd x64base

Core build -- what CI builds on every push, on Windows/MSVC and Ubuntu/GCC. It is the lean product: no LMDB index store, no TUI. It needs VCPKG_INSTALLATION_ROOT pointing at a vcpkg checkout; on Ubuntu, CI also installs ninja-build autoconf autoconf-archive automake libtool.

cmake --preset core-vcpkg
cmake --build --preset core-vcpkg
ctest --preset core-vcpkg

Full development build -- what the maintainer runs, with the LMDB-backed CDX store. Windows needs VCPKG_ROOT set; the Linux/WSL preset uses Ninja.

cmake --preset pro-md          # Windows, MSVC
cmake --build --preset pro-md-Release

cmake --preset wsl             # Linux / WSL
cmake --build --preset wsl-Release

Source-evidenced Every command above is read from CMakePresets.json and .github/workflows/ci.yml on main; CI results are public on the repository's Actions tab. This page has not run them from a fresh clone, and the system packages the wsl preset expects are not listed yet (GAP). See Getting started for the first session once it builds.

External dependencies

LMDB backs the CDX key store and SQLite is compiled in as a companion carrier and verification oracle. Both stay external libraries rather than being absorbed into the engine.
